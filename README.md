# Harsh Patel | Portfolio

Personal portfolio across research, data analytics and data engineering.

Live website: [harshp10101.github.io](https://harshp10101.github.io/)

## Website files

- `index.html`: content, structure, metadata and links.
- `styles.css`: responsive editorial design and motion styles.
- `script.js`: hero interactions, capability explorer, navigation and accessibility behavior.
- `assets/`: optimized hero artwork and the Maven Market dashboard image.
- `favicon.svg` and `og.png`: browser icon and social preview.
- `.nojekyll`: serves the site as ordinary static files on GitHub Pages.

No framework, package installation or build step is required. Preview with a local static server. GitHub Pages publishes the root of the `main` branch.

The previous website remains available in Git history. This redesign preserves the project's history without a force push.
