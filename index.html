01 / Signature project

What actually moves property value across a city?

A statistical investigation of 1.2 million Edmonton assessment records, built to separate citywide headlines from neighbourhood-level change.

The question
How did assessed values shift from 2022 to 2024, and which property characteristics were associated with the difference?
The investigation
Matched properties across years, then used t-tests, ANOVA with Tukey HSD and OLS regression.
The implication
A single citywide average can hide sharply different neighbourhood trajectories.

Python / Pandas / Statsmodels / SciPy
