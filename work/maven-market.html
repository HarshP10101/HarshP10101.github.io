02 Retail intelligence / Power BI

Maven Market Retail Analytics

How can a retail team see what needs a closer look?

18,325current-month transactions

Tools & sources

Power BI · Power Query · DAX · Star schema

View project on GitHub ↗ Original dashboard screenshot ↗

01 / Context

Why it mattered

Revenue can tell a different story from profit or returns. I used data for the fictional retailer Maven Market to build a report that kept those measures in view and let readers compare stores, regions and product brands.

02 / Method

How I approached it

I cleaned the CSV exports in Power Query, modelled transactions and returns in a star schema and wrote reusable DAX measures. I spot-checked the measures against expected results before assembling the dashboard.

03 / Findings

What came out of it

In the dashboard’s current-month view, transactions reached 18,325 against a goal of 17,339 and profit reached $71,682 against a goal of $67,872. The same view shows 496 returns alongside the sales measures.

04 / Takeaway

What I learned

A useful report depends on consistent measures. Keeping time windows and goals visible makes it easier to interpret the KPIs before drilling into a brand or store.
